# Team Samagra — Short Film Website

A static Cloudflare Pages-ready website for the Samagra Club short film.

## Video
The player embeds:
https://fembed.co/embed/lcW-dPNdS_jGM

## Deploy on Cloudflare Pages
1. Upload this folder to a GitHub repository, or upload the project directly through the Cloudflare Pages/Workers dashboard.
2. For a plain static site, no build command is required.
3. Use the project root as the output directory.
4. Deploy.

If the Fembed player changes its embedding policy, update the iframe URL in `index.html`.
